Dynamic Worlds
Fresh terrain, same playthrough.

Dynamic Worlds is a tModLoader utility mod that regenerates Terraria terrain without throwing away the playthrough built on top of it.

Use /regenworld [seed] to:
- snapshot world progression and preserved data
- save the world cleanly
- generate fresh terrain
- restore protected builds, exact tiles, NPC state, and progression
- reload into the regenerated world

What gets preserved:
- Hardmode, game mode, evil type, ore tiers, boss flags, event flags, invasions, and world identity
- Town NPC roster, names, positions, and preserved housing when a valid home survives
- Bed spawn handling with safe fallback to world spawn
- Anchored tiles, structure zones, Biome Dowser zones, and preserved container contents
- Vanilla pylon registration and repair after restore
- Calamity progression and world state when Calamity is installed

Main systems:
- Reality Anchor: preserve exact tiles, walls, liquids, wires, actuators, and containers
- Reality Eraser: force marked areas to clear to empty space after every regen
- Structure Anchor: preserve whole builds as movable structure zones
- Biome Dowser: preserve vanilla pylon structures and relocate them to matching biomes
- Unified overlay system: hold any world tool to see all saved world data together
- Automatic scheduler: trigger regen by in-game days or real-world days
- Pre-regen backup system: keeps rolling backups of the old world before regen runs

Multiplayer support:
- synced anchors, erasures, structure zones, and Biome Dowser zones
- server-admin /regenworld with countdown, disconnect, regen, and reconnect flow
- configurable multiplayer regen permissions
- optional scheduled multiplayer regen

How the tools work:
- Reality Anchor: left-click single tiles, drag rectangles, inventory right-click restore when cheats are enabled
- Reality Eraser: left-click single tiles, drag rectangles, inventory right-click clear when cheats are enabled
- Structure Anchor: click-drag a structure zone, Shift-click inside a zone to remove it
- Biome Dowser: click-drag a pylon zone, right-click to open settings, Shift-click inside a zone to remove it
- Hold any world tool to see anchors, erasures, structure zones, and Biome Dowser zones together

Useful commands:
- /regenworld [seed]
- /multiregen <count> [seed]    single-player only
- /snap
- /dwtools [player]
- /dwtool <anchor|eraser|structure|dowser|prefab|all> [player]
- /dwinfo
- /dwzone [list|clear|clearall] [id]
- /clearzones
- /dwperm
- /dwregenconfig
- /revealmap                      requires Allow Cheats
- /hardmode [on|off]              requires Allow Cheats
- /down <bossOrEvent>             requires Allow Cheats
- /killduplicatenpcs              requires Allow Cheats

Config highlights:
- Enable Scheduled Regen
- Scheduled Regen Interval (Days)
- Scheduled Regen Mode: in-game days or real-world days
- Enable Multiplayer Regen
- Enable Scheduled Multiplayer Regen
- Multiplayer Regen Countdown (Seconds)
- Multiplayer Regen Disconnect Timeout (Seconds)
- Announce Multiplayer Regen Countdown
- World tool, zone, tool-command, regen-command, and cheat-command permissions
- Trusted Players list
- Allow Cheats
- Regenerate World on Death    single-player only
- Preserve Evil Type
- Randomize World Each Regen
- Preserve Dungeon Side        planned, not implemented
- Preserve Biome Features      planned, not implemented

Compatibility:
- best when the same mod list stays installed before and after regen
- Calamity support preserves boss progression, difficulty modes, acid rain, Boss Rush state, and related world data
- modded items in preserved chests and dressers are supported through tModLoader item serialization
- modded tiles, walls, and town NPCs often survive if their source mods remain installed
- weaker compatibility for custom pylons, unusual tile entities, and major worldgen-overhaul mods

Important limits:
- multiplayer regen is a server maintenance flow, not seamless live regeneration
- /multiregen is still single-player only
- Biome Dowser currently supports vanilla pylons only
